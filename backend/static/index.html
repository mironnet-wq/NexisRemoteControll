Provisionamento Android

Para smartphones comerciais novos ou resetados:

  1. No Android Studio: Build Variants → provision, depois Build APK.
  2. Factory reset no celular → tela Welcome → toque 6 vezes.
  3. Escaneie o QR Code (confirme Pronto: SIM abaixo do QR).
  4. O aparelho instalará o agente e se conectará automaticamente.

Coletores Zebra MC33xx

Para coletores corporativos industriais:

  1. Abra o aplicativo nativo StageNow.
  2. Escaneie o código de barras gerado pelo console Nexis.
  3. O coletor fará a instalação silenciosa e configurará as permissões via MX.
